# Ask REPWISE integration

The integration is disabled by default. No provider key, paid AI call, production migration or deployment is included in this change. Device journaling continues to work. The local preview is calculated by REPWISE, not generated by AI.

## Experience

The training sidebar opens Ask REPWISE. Users can type or dictate a question, review its transcript, and explicitly send it. Browser speech recognition may use the browser vendor's remote service. Speech synthesis is optional and initially muted; device and online voices depend on the browser. No custom speech model is trained or required.

Workout sharing is off by default. Opting in previews the exact snapshot before sending. Notes, workout names, templates, account IDs and target IDs are excluded. The snapshot contains training preferences and up to 60 matching sessions; one exercise can be selected. Changing sharing or exercise scope clears the conversation and cancels pending work. Leaving the tab removes the conversation from memory. Already transmitted data cannot be recalled; provider retention policies still apply.

The service recomputes evidence using the same deterministic analysis engine as the app. Only calculated summaries, the question and recent conversation go to the model through Vercel AI Gateway. Model configuration supports OpenAI and Google. Reference URLs come from the application's curated catalog. Observations, app guidance and model hypotheses are displayed separately. The assistant has no tools or journal write capability.

This is not a newly trained prediction model. The reference catalog is intentionally small and includes an explicitly identified industry source. Source IDs are validated, but citation relevance and factual accuracy still require human evaluation. Prompt instructions constrain personal advice; they cannot guarantee an AI answer is correct. Live provider evaluation is required before activation.

## Connect later

1. Connect the existing Supabase journal authentication and migrations. Review the new `202610260001_coach_limits.sql` migration before applying it. It adds only a quota table and service-only function; it does not change workout records.
2. Configure Edge Function secrets: `AI_GATEWAY_API_KEY`, `REPWISE_COACH_MODEL` (an available `openai/...` or `google/...` model supporting structured output), `REPWISE_ALLOWED_ORIGINS=https://rep-wiser.vercel.app`, and `REPWISE_COACH_ENABLED=true`. Supabase supplies its URL and anon/service-role keys. Keep provider and service-role keys exclusively on the server. Check current model availability, pricing and data-retention settings before enabling; set a gateway budget as well.
3. Run `pnpm build:coach` before `supabase functions deploy ask-repwise`. This builds the shared engine and validation into the Deno function. Keep JWT verification enabled. The function additionally verifies the JWT using Auth and rejects anonymous accounts. Never use `--no-verify-jwt` for deployment.
4. Set the frontend `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, and `NEXT_PUBLIC_REPWISE_COACH_ENABLED=true`, then rebuild. The anon key is public; a service-role or provider key must never use a `NEXT_PUBLIC_` name.
5. Test a real signed-in request, expired session, opt-in/out, quota exhaustion, cancellation, typed and dictated questions, and spoken answers on desktop and phone. Verify source relevance, hallucination resistance and pain-related responses with the chosen model before production activation.

## Boundaries and checks

The endpoint enforces an exact origin allowlist, verified identity, bounded JSON, strict schema, consent/snapshot consistency, a 25-second generation timeout, no SDK retries, structured responses, and known citation IDs. Error responses do not expose provider details. Quota is stored in PostgreSQL, serialized across concurrent requests: 5 per user per UTC minute, 20 per user per UTC day and 200 globally per UTC day. Failed generation consumes a reserved request. These request limits are not a monetary spend cap.

Monthly comparisons use UTC dates, first and last completed entries in the supplied snapshot, comparable loads/set counts/rep ranges, and total working reps. They exclude changed-load exercises and are not a universal strength ranking. Drafts and missing measurements are called out. Larger histories are truncated and labeled.

Run `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm build:coach`, `pnpm build`, and `pnpm exec playwright test`. CI also tests quota permissions/concurrency against a disposable local Supabase. Unit tests inject a fake generator to exercise the boundary; they do not establish the quality of any live model. Production credentials are never needed for these checks.
